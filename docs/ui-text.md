# 申請管理システムの画面の文言

テンプレートに含まれる画面の文言を、画面と要素ごとに並べる。文言を変えるときは、先にこの表を直してから、コードに写す。表記は次の方針にそろえる。

- 漢字・仮名と半角の英数字の間に空白を入れない（例：20件、R08-001060を削除しました）
- 和文の中のコロンは、全角の「：」にする（例は「キーワード：公園」）
- 受付番号と件名を並べるときは、件名を「」で囲む（例：R08-001012「中小企業デジタル化支援補助金」）
- 見本の画面であることを伝える文言には「見本」を使う

## 対象の画面

対象の画面と、利用者がそこですることは次のとおり。利用者は、自治体で申請の受付と審査をする職員である。

| 画面 | 目的 | 利用者 |
| --- | --- | --- |
| 共通（ヘッダーとメニュー） | 画面を移り、お知らせと自分のアカウントを確かめる | 職員 |
| ダッシュボード | 受付の件数と処理の状況を見て、今日の仕事を決める | 職員 |
| 申請一覧 | 申請を探して開き、担当者の変更や削除をまとめてする | 職員 |
| 申請の詳細 | 申請の内容を確かめ、承認するか差し戻すかを決める | 審査の担当者 |
| 新規申請と編集 | 申請の内容を入力し、確かめてから申請する | 窓口の職員 |
| 設定 | プロフィール、通知、画面の表示を変える | 職員 |
| ログイン | メールアドレスとパスワードでログインする | 職員 |
| ページが見つからない画面 | 開こうとした画面がないと知り、別の画面へ移る | 職員 |
| ページを表示できない画面 | システムの不具合で開けないと知り、やり直すか問い合わせる | 職員 |

## 用語表

言い方が揺れやすい語は、次の「使う語」にそろえる。

| 使う語 | 使わない語 | 意味 |
| --- | --- | --- |
| 申請 | 案件、届け | 申請者から受け付けた1件の手続き |
| 受付番号 | 申請番号、ID | 申請ごとに振る「R08-001060」の形の番号 |
| 差戻し（名詞）、差し戻す（動詞） | 差し戻し（名詞）、差戻す、却下 | 申請者に修正を求めて返すこと |
| 承認 | 許可、決裁 | 申請の内容を認めること |
| 担当者 | 審査者、担当 | 申請の審査をする職員 |
| 削除 | 消去、除去 | 申請を一覧から取り除くこと |
| 元に戻す | 取り消し、アンドゥ | 削除した申請を一覧に戻すこと |
| 見本 | サンプル、表示例、デモ | 実際には送信や保存をしない、テンプレートの画面であること |
| 読み込む | ロード、取得 | 画面に出すデータを受け取ること |
| 確かめる | 確認する（動詞の場合） | 内容が合っているかを見ること。「確認事項」「入力内容の確認」のような名詞はそのまま使う。 |

## 未決定の文言

決まっていない文言は次のとおり。

- 日時の表示形式：既定は「年/月/日」を数字と斜線で並べる形にしている。本文を「2026年10月31日」の形にするかは、設定画面の「日付の形式」で利用者が選ぶ作りのため、テンプレートを使う組織が決める
- ログインのエラーの書き方：メールアドレスとパスワードのどちらが違うかを示すと、登録の有無が分かってしまう。どこまで示すかは、テンプレートを使う組織の情報セキュリティの担当者が決める
- 架空のデータ（人名、組織名、件名）：見本のため仮の値にしている。実際の運用に合わせた例は、テンプレートを使う組織が決める
